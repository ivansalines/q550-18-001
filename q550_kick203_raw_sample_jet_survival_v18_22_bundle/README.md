# Q550 v18.22 — Raw-Sample Noise, Jet Reconstruction & Hidden-Direction Survival Audit

## The question

Do hidden perturbation directions that are numerically observable in the third Taylor jet
remain recoverable **when the only observations are noisy raw time samples**?
Compare, on the **same samples and same synthetic noise realization**, two estimators:

1. **Direct full-window estimator:** estimate the fixed ten-dimensional perturbation
   using the authentic frozen tangent propagator \(H\Phi(t,4)\). Do not differentiate.
2. **Polynomial-to-jet estimator:** fit a local polynomial (degrees 3 or 5) to the raw
   samples, extract coefficients through degree 3, propagate their full correlated
   covariance, and estimate the same state using the Q550 Taylor-jet observability map.

A model-based full-window estimator is naturally advantaged relative to its compressed
local-Taylor approximation: loss of information and truncation error **are not physics**.
This audit measures those losses without interpreting them as hereditary memory.

## Covariance-aware polynomial compression

For raw samples `Y` of `m` observable components at offsets `delta`:

```
V_ik = (delta_i/width)^k,  k=0..degree
B = pinv(V)
coefficient_estimate = B @ Y
K = B[:4,:] @ B[:4,:].T
Cov(coefficient_estimate[:4]) = sigma**2 * (K kron I_m)
local_jet_k = width**k/k! * H M_k  # k=0..3
```

The estimator whitens `K kron I_m` before least-squares state reconstruction.
This accounts for the nontrivial correlations generated by differentiating noisy
raw samples. `degree=5` is a **local smoother**; only the first four fitted
coefficients are compared with the third-order jet map. The latter has finite
window truncation bias, explicitly measured and reported.

Raw noise (`sigma=[1e-5,1e-4,1e-3]`) is synthetic, independently drawn for each
sample and output channel, and applied to the paired difference response
**normalized by** `2 epsilon`. `128` trials for each frozen configuration.
It is **NOT a measured physical noise floor**. For example `epsilon=1e-5`
and `sigma=1e-4` in the normalized response correspond to a raw difference
noise standard deviation `2e-9` in the observable's units, not sensor units.

## Scientific limitations

* Ranks are local numerical tangent properties, not global observability proofs.
* The estimators assume a known original Q550 tangent propagator and fixed
  diagnostic observer. The tangent reconstruction uses a declared Euclidean
  coordinate gauge; change coordinates/physical noise jointly before comparison.
* Polynomial reconstruction may be both noise-limited at small widths and
  truncation-biased at large widths. “Survival” is observer- and noise-dependent.
* The same-state full 11D determinism remains untouched: these tests do not
  establish constitutive hysteresis, an intrinsic flip, or a preferred metric.
* Frozen Monte Carlo results must not be passed off as independent nonlinear
  original-ODE results. Only the server script produces that check.

Documentation and Python comments are in English for executable genealogy.
