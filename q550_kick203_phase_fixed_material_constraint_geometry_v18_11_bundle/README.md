Now split the Q550 ODE state into `y=(z[0:10], theta=y[10])` and use the original archived v18.7 Jacobian/cocycle to verify

```

z'(s) = F(z, theta)
J = [A  b]       P = [Phi  q]
    [0  0]           [0    1]
Phi' = A Phi    q' = A q + b
```

The phase-fixed perturbation sector `delta_theta=0` is invariant under the tangent transport. It is NOT a closed autonomous 10D state flow. A phase-labelled time-dependent leaf `theta(s)=theta(s0)+2*pi*(s-s0)` is a clock identity, not a material constraint. All phase structure reported from the frozen checkpoint is samplewise/numerical, supplemented by an independent server replay of the original hash-pinned ODE.

The plane `span(E,K2)` has a Euclidean-gauge-dependent orthogonal projector `Pi=U(U^TU)^-1 U^T`, with `U=[E,K2]` represented in its invariant 10D variation sector. Its rate splits algebraically:

```

U'_source = slope * [0, Phi g]
Pi' = (I-Pi) U' U^+ + ((I-Pi) U' U^+)^T
```

The homogeneous-transport and source-birth projector rates are linear in `U'`, but their norms need not add. Singular values, Grassmann speeds, principal angles and projector magnitudes use **the declared 10D Euclidean gauge only**; the exact rank of a plane is algebraically invariant under invertible coordinate changes.
